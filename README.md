# AI Product Co-Creation Demo

一个 AI 原生工业产品共创概念原型，探索非专业用户如何从模糊意图出发，在 AI 的持续追问和反馈下生成、修改并交接一个产品半成品模型。

## 核心流程

1. 上传参考图片并描述模糊想法。
2. AI 生成可交互的产品概念模型。
3. AI 围绕使用环境、承重与折叠目标逐步追问。
4. 用户点击模型构件，通过自然语言继续修改。
5. AI 提示修改带来的连带工程影响。
6. 用户查看爆炸结构，并将模型与设计上下文传递给专业工程师。

## 运行方式

直接在浏览器中打开 `index.html` 即可。该原型为单文件离线演示，不需要安装依赖或连接后端服务。

## 说明

- 这是用于验证交互范式的概念原型，不是生产级 CAD 工具。
- 模型、对话和修改路径均为预设演示。
- 专业工程师仍需完成材料、结构、承重、安全和制造可行性验证。
